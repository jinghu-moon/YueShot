# YueShot 当前发行范围与已知限制

2026-11-09。公开 0.1.3 Beta 是测试发行，尚未完成稳定发行资格。

| 范围 | 当前状态 |
| --- | --- |
| 平台 | Windows x64；ARM64 没有设备资格，不承诺支持 |
| 颜色 | 默认 SDR；`hdr-capture`、`avif` 的构建检查不等于默认开启或完成实屏资格 |
| 安装 | 当前用户安装，dev/beta/stable 身份和数据独立；默认卸载保留数据 |
| 签名 | 按维护者选择不做 Authenticode，Windows 可能显示未知发布者；更新清单仍必须通过 Minisign 认证 |
| 更新渠道 | Beta 已配置公钥和公开源；dev/stable 未配置，检查更新会明确失败 |
| 更新恢复 | 正常在线升级已通过；文件锁/暂存清理有回归。公开 0.1.3 在提取写失败时仍可能残留事务；[本地修复](upgrade-failure-qualification.md) 已验证、未发布。断电后的自动恢复未实现，既有残留事务只检测并保留 |
| 安装并发 | 同名 YueShot 进程存在时保守拒绝安装/卸载；不强杀，不承诺不同用户/渠道同时更新 |
| 安装器显示 | 中文/英文、系统字体、system-DPI-aware；跨不同 DPI 显示器移动仍可能被 Windows 缩放 |
| 系统资格 | 另一台 Build 19044 普通用户通过了指定 0.1.2 安装/关闭回归；没有据此声明 0.1.3 的完整最低系统、无预装运行库或所有动态加载资格 |
| 稳定性 | 登录自启、Explorer 重启、单轮睡眠恢复已获用户确认；重复循环、资源/原生崩溃稳定性及全部多屏/DPI 尚未覆盖 |
| 密钥 | 加密备份、恢复签署、拔插复读已通过；轮换和丢失/泄露后的带外补救尚未演练 |
| 分发条款 | Rust/字体/图标材料与官方运行库来源已记录；微软运行库下游条款及 AGPL System Libraries 适用仍需审查 |

具体版本、构建与证据分别见 [生命周期](lifecycle.md)、[在线更新](updates.md)、[分发权利](distribution-rights.md)。
后续本地修复不能追溯视作已公开安装器已经修复，须通过新候选和独立发布流程交付。
